دفتر هوشمند مدیریت کلاس ششم - نسخه PWA

فایل‌ها:
index.html
manifest.json
sw.js
icons/icon-192.png
icons/icon-512.png

نحوه استفاده:
1) همه فایل‌ها را با همین ساختار در ریشه Repository گیت‌هاب قرار بده.
2) GitHub Pages را برای branch اصلی و پوشه ریشه فعال کن.
3) آدرس ساخته‌شده را با Chrome باز کن.
4) بعد از یک بار اجرای آنلاین، Service Worker فایل‌های اصلی را ذخیره می‌کند و برنامه در حالت آفلاین هم باز می‌شود.
5) اطلاعات برنامه در localStorage همان دستگاه ذخیره می‌شود.
6) برای خروجی و بازیابی پشتیبان، اینترنت برای خود برنامه الزامی نیست؛ اما اگر کتابخانه Excel از CDN هنوز در cache نباشد، خروجی Excel ممکن است نیاز به یک بار اتصال اینترنت داشته باشد. پشتیبان JSON همیشه بدون اینترنت کار می‌کند.
